# AI Foundations for Managers (MGT 409), Fall 2026

## ☕ Final project: [Coffee Chat Copilot](coffee-chat-copilot/)

An AI agent app that helps Yale SOM students run investment banking coffee chats. It drafts the finance club's
emails within the 15-minute rule, finds 90-minute windows that work around classes and the Metro-North ride to NYC,
plans multi-bank NYC days, and nudges you to eat, rest, and see friends.

**Run it:** see [`coffee-chat-copilot/README.md`](coffee-chat-copilot/README.md). In short:

```bash
cd coffee-chat-copilot
pip install -r requirements.txt
python run.py          # http://127.0.0.1:8000
```
